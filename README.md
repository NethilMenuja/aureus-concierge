# 👑 Aureus Concierge — Ultra-Luxury B2B Procurement Platform

Aureus Concierge is a high-end B2B luxury procurement platform connecting private estate managers with verified gourmet suppliers.

## 🌟 Key Features

* **Hyper-Local Map Engine**: Interactive dark-themed Leaflet.js map with custom spatial radius matching.
* **Instant Automated Invoicing**: Real-time client-side PDF invoice generator built with `jsPDF`.
* **Real-Time Notification Engine**: Automated transactional emails powered by `Resend API`.
* **Supplier Operations Dashboard**: Dynamic order status tracking (`Pending` → `Dispatched` → `Delivered`).

## 🛠️ Tech Stack

* **Framework**: Next.js 14 (App Router)
* **Styling**: Tailwind CSS v4 (Luxury Dark Aesthetic)
* **Database & Auth**: Supabase
* **Mapping**: Leaflet.js + CartoDB Dark Matter Tiles
* **Email Engine**: Resend API
* **PDF Engine**: jsPDF & jsPDF-AutoTable
* **Deployment**: Vercel
